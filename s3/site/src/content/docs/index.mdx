EspOS is an open-source operating system for the ESP32-S3 family. The firmware is the OS. It runs on:

- **the S3 desks**: colour touch screens, the 3.5" ES3C35P and the 2.8" ES3C28P (one firmware finds its board). Apps, games and data are packages that you install from the store or copy onto the memory card, so a new app needs no new firmware;
- **the EspOS Bot**: a small ESP32-S3 board with a 0.96" OLED, a microphone and a speaker, for the dog assistant you talk to.

Both sync with an EspOS server: the hosted one at espos.dev, or your own.

These docs explain how to build apps in JavaScript, test them in the simulator or in QEMU, package and publish them, and port the OS to a new board.

## Where to start

1. [What is EspOS](/getting-started/introduction/): the idea, what you can build today and the supported boards.
2. [Set up your tools](/getting-started/install/): the toolchain, the `espos` CLI and `espos doctor`.
3. [Your first app](/getting-started/first-app/): a tea timer in JavaScript with a countdown, a notification that fires with the app closed, and saved state.
4. [The development loop](/getting-started/workflow/): create, run in the simulator, check, package, install on a device and publish.
5. [Put your app on your own device](/guides/my-apps/): a developer key from espos.dev, `espos upload`, and your app installs on your EspOS devices over WiFi.

Already building an app? Go to the [JavaScript API reference](/reference/js-api/) or the [manifest fields](/reference/manifest/). New in EspOS 0.5.0: [languages](/guides/languages/) (`app.lang`) and [landscape](/guides/landscape/) (`app.screen` and half cards).

## Open source

Everything is in one public repository, [github.com/songhieu/espos](https://github.com/songhieu/espos):

| Folder | What | Licence |
|---|---|---|
| `s3/` | The firmware for the S3 desks and the EspOS Bot, the SDK and the `espos` CLI, the simulators, the tools and the sources of these docs | Apache-2.0 |
| `server/` | The self-hosted server, its web app and the dog assistant with your own AI and voice services | AGPL-3.0 |

Releases up to commit `fac0c54` stay MIT. Support for the Xteink X4 e-ink reader is paused: its firmware is in the repository's history up to commit `9059678`. To build from the sources, see [Set up your tools](/getting-started/install/); to run your own server, [Self-hosting](/roadmap/self-hosting/).
